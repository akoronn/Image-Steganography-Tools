# 画像ステガノグラフィーツール
## 内容
PNG画像に文字列を格納するツール。

## 目標
https://zk-phi.github.io/argtools-jp/apps/stegano/?ref=trap.jp に検知されない程度のものが目標。

### 識別子
情報が埋め込まれている画像かを確認するためのもの。  
ASCIIで「stego」に対応するbyte列を採用。  
1110011 1110100 1100101 1100111 1101111  

### データ量
埋め込まれているデータ量を示す。  
画像の大きさによるが、最大格納数は2^(24) = 16,777,216bit

## 現状

### ver 1.0.0
データ構造:  
[24bit データ量] [1bit 暗号フラグ] [Nbit 本文]  

データを順番にLSBで記録していくため、解析されやすい。

### ver 2.0.0 (最新)
データ構造:  
[40bit 識別子] [24bit データ量] [Nbit 本文]  

暗号化オプションは廃止し、指定したシードに従って画像ピクセル内にランダムに配置される。
